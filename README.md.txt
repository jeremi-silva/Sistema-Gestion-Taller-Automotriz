
# Sistema de Gestión de Taller Automotriz

## Descripción

Aplicación de consola desarrollada en Java para gestionar información básica de un taller automotriz.

El sistema permite registrar clientes y vehículos, consultar el inventario de repuestos, generar órdenes de trabajo y consultar información de vehículos y mecánicos.

## Tecnologías utilizadas

- Java
- Programación Orientada a Objetos
- NetBeans
- Git y GitHub
- ArrayList para almacenar información en memoria
- Scanner para la entrada de datos

## Estructura del proyecto

- `modelo`: clases que representan las entidades del sistema.
- `servicio`: lógica de gestión del taller y autenticación.
- `vista`: interacción con el usuario y ejecución del programa.

## Funcionalidades

- Inicio de sesión.
- Registro de clientes.
- Registro de automóviles y motocicletas.
- Consulta de vehículos.
- Consulta de inventario de repuestos.
- Creación de órdenes de trabajo.
- Consulta de órdenes.
- Reporte de mecánicos.

## Ejecución

1. Descargar o clonar el repositorio.
2. Abrir el proyecto desde Apache NetBeans.
3. Verificar que se encuentre instalado un JDK compatible.
4. Ejecutar el archivo `Main.java`, ubicado en el paquete `vista`.

## Almacenamiento

La información se administra en memoria mediante colecciones ArrayList.
Los datos ingresados durante la ejecución no se conservan al cerrar el programa.

## Proyecto académico

Desarrollado como parte de la asignatura de Programación Orientada a Objetos.
